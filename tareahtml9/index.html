Colores Multinavegador

Hay mas de 160 colores con nombre, que son compatibles con la mayoria de los navegadores modernos. Estos nombre se pueden usar directamente en CSS para aplicar colores a elementos sin especificar valores de algun modelo de color.

Por Ejemplo:

  • Negro
  • Blanco
  • Salmon
  • Azul
  • Verde

Borde

Para que a un elemento html se le aplique color a su borde se necesitan 3 propiedades: border-style, border-color, border-width
