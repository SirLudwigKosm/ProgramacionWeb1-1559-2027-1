Resumen HTML: Principales conceptos y etiquetas

Esta Pagina va a resumir los principales conceptos y etiquetas vistas en la clase de programacion web 1, en el modoulo HTML

Conceptos Principales HTML

Concpeto HTML

El Lenguaje de Marcado de Hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

un Elemento HTML es la unidad basica de estructura y contenido en una pagina web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqueta que se utiliza para comunicarse con el navegador a traves de los metadatos, permite mejorar el SEO, ademas se enlazan archivos externos de etilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra pagina web

Contenedores Semanticos

<header> Es una etiqueta utilizada para el contenido introductorio de una pagina web, contiene el Logo, el menu de navegacion prinicpal, el nombre de la empresa, etc
<nav> Etiqueta utilizada para el menu de navegacion principal suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal, no debe de haber mas en la pagina
<main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocara el contenido principal de nuestra pagina
<section> Es una etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
<article> Es una etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Es una etiqueta que normalmente se encuentra hasta el final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otro informacion complementario
<aside> Esta etiqueta representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras paginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son :

href="https://wa.mi/1234567891"
Este valor envia un whatsapp a un numero especificado
href="mailto:example@gmail.com
Enviaba un correo a un mail especifico
